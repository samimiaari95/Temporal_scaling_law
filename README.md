# Temporal Scaling Law

## analytical solution
analytical_solution.py is the script for solving the analytical solution by srivastava and yeh 1991<br>

## scaling law
the script scaling_law.py includes the solution of the analytical and plots of analytical and numerical solutions. It also includes the soil texture fitting functions.<br>
inf_inventory.py is the python code for generating the plots of infiltration scaling law.<br>
exf_inventory.py is generates the plots for the exfiltration process.<br>
## utilities
random_functions.py is the main file for utilities and functions for all tasks<br>
utils.py is a script that includes generalized functions that are called from other scripts
